# 使い方マニュアル

---

## 画面構成

アプリは上部の5つのタブで切り替えます。

| タブ | 用途 |
|------|------|
| 📅 日 | 日々の支出入力・確認 |
| 📆 週 | 週間集計 |
| 🗓 月 | 月間集計・予算対比・カレンダー |
| 📊 年 | 年間収支・前年比 |
| 📌 定期 | 収入・固定費・特別出費・予算設定 |

---

## 日タブ：日々の入力

### 支出を追加する

1. 日付を選択（デフォルトは今日）
2. カテゴリを選択（食費・外食・日用品など）
3. 店名・内容を入力（任意）
4. 金額を入力
5. **「追加」** ボタンをタップ

**電卓を使う場合：**  
金額欄の右にある 🧮 をタップすると電卓が開きます。計算後「＝」を押すと金額欄に自動入力されます。

### 入力した支出を修正する

- 一覧の ✏️ ボタンをタップ → フォームに内容が入ります
- 修正して **「更新」** ボタンをタップ
- キャンセルは「✕ 編集キャンセル」をタップ

### 支出を削除する

一覧の **×** ボタンをタップ → 確認後削除

### 備考メモ

その日のメモを自由に記入できます。「メモを保存」で保存してください。

## 週タブ・月タブ・年タブ

### 期間の移動

← / → ボタンで前後の週・月・年に移動できます。

### 月タブのカレンダー表示

「カレンダー」ボタンをタップすると、月のカレンダー形式で日別支出と週合計が確認できます。

### 月タブの予算対比

定期タブで予算を設定すると表示されます：
- 月間予算に対する使用率（進捗バー）
- カテゴリ別の使用額・残り額・バー

### 前月比・前年比

前の期間と比較した増減を色分け表示します（↑赤：増加、↓緑：減少）。

### クレカ支払いメモ（月タブ）

「💳 クレカ」セクションでクレジットカードの月次引き落とし額を記録できます。

## 定期タブ：収入・固定費・特別出費の管理

### 収入の設定

1. 「収入」サブタブ →「＋ 人を追加」で人物を登録
2. 登録した人の「12ヶ月入力」から月別の給与・ボーナス等を入力

### 固定費の設定

1. 「固定費」サブタブ → 大分類（家賃・サブスクなど）の下の「＋ 項目を追加」
2. 「12ヶ月入力」で月別の金額を入力
3. 毎月同じ場合は「1月の値を全月にコピー」が便利です

### 特別出費の記録

発生した特別支出（旅行・家電購入など）を日付ベースで記録します：

1. 「特別出費」サブタブ
2. 日付・大分類・項目名・金額を入力
3. **「追加」** をタップ

記録は月別にまとめて表示されます。

### 予算設定

1. 「予算設定」サブタブ
2. **月間変動費予算**：毎月の変動支出の目標金額を入力
3. **カテゴリ別予算**：食費・外食などカテゴリごとの月額目標を入力
4. 「保存」をタップ

**繰り越し機能：**「余った分を翌月に繰り越す」にチェックを入れると、先月の余りが今月の予算に上乗せされます。

## ファミリーコードの管理

### 家族と共有する

1. 画面上部のコード表示エリアでファミリーコードを確認
2. そのコードを家族に伝える
3. 家族がアプリを開いてコードを入力すると、同じデータが表示される

### コードを変更する

「コード変更」ボタンから変更できます。  
⚠️ コードを変更すると以前のコードのデータとは切り離されます。

---

## データの同期状態

画面上部の同期ステータスで確認できます：

| 表示 | 意味 |
|------|------|
| ✅ 同期済み | 最新の状態 |
| 🔄 接続中 | 接続処理中 |
| ❌ オフライン | ネットワーク未接続 |

---

## ホーム画面への追加（スマホ）

**iPhone（Safari）：** 共有ボタン → 「ホーム画面に追加」  
**Android（Chrome）：** メニュー → 「ホーム画面に追加」

アプリのように起動できるようになります。

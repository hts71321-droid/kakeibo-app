# 家族で使えるクラウド家計簿アプリ — 商品説明・アピールポイント

> **一度セットアップすれば、家族全員がリアルタイムで同じ家計簿を共有できます。**
> HTMLファイル1枚＋無料クラウド（Firebase）で動く、シンプルで高機能な家計管理ツールです。

---

## こんな方におすすめ

- 夫婦・家族で家計を一緒に管理したい
- Excelや手書きは面倒、でもサブスクアプリには課金したくない
- スマホからサクッと入力したい
- 支出の傾向や予算達成度を視覚的に確認したい

---

## 主な機能

### 👨‍👩‍👧 家族でリアルタイム共有
- **ファミリーコード**（合言葉）を決めるだけで家族全員が同じデータを共有
- 夫が外でスーパーに寄って入力 → 妻のスマホにもすぐ反映
- Google の Firebase（無料枠）を使用。月間10万件以上の更新でも無料

### 📅 かんたん日々入力
- カテゴリ・店名・金額を入力するだけ
- **内蔵電卓**で「2,800＋500」のような計算をしてそのまま登録
- 入力済みの項目をタップして**その場で修正**可能

### 💰 予算管理
- 月間の変動支出予算を設定
- **カテゴリ別予算**（食費は3万円など）を設定し、進捗バーで見える化
- 予算超過時に一度だけアラート（翌月まで再表示しない）
- **余った予算を翌月に繰り越す**機能付き

### 📊 多彩な分析ビュー
| タブ | できること |
|------|-----------|
| 日 | 日別入力・カテゴリ集計 |
| 週 | 週間の支出傾向 |
| 月 | カレンダー表示・カテゴリ予算対比・前月比 |
| 年 | 年間収支・前年比・月別推移 |

### 📌 定期費・収入の管理
- 給与・ボーナスなど収入を月別に記録
- 固定費（家賃・サブスク・保険など）を12ヶ月分管理
- 特別出費（旅行・家電など）を日付ベースで記録
- 毎月の収支差額を自動計算

### 💳 クレカ支払いメモ
- クレジットカードの月次引き落とし額をカード別に記録
- 月タブから確認可能

## 技術仕様

| 項目 | 内容 |
|------|------|
| ファイル構成 | `index.html` 1ファイルのみ |
| ホスティング | GitHub Pages（無料）|
| データ保存 | Firebase Realtime Database（無料枠で十分）|
| 対応端末 | PC・スマートフォン・タブレット（iOS/Android対応）|
| インストール | 不要（ブラウザで動作、ホーム画面追加でアプリっぽく使える）|
| ランニングコスト | **0円**（無料枠の範囲内で家族数人の利用は十分）|

## 無料で使えるの？

はい。以下はすべて**完全無料**です：

- GitHub（コード管理・ホスティング）
- Firebase Realtime Database（家族数人の利用では無料枠で十分）
- アプリ本体の使用

支払情報を登録しなければFirebaseは課金されません。
